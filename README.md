This repository contains code and materials related to Chapter 20 on Model Evaluation.

Model evaluation is a critical step in the machine learning pipeline. This chapter covers various techniques and metrics used to assess the performance of machine learning models.

- Performance assessment techniques

Run the Python scripts in this repository to explore various model evaluation techniques.
